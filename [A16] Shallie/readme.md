You will need to run gust_enc from gust_tools to decrypt the xml.e files.

Run `python shallie_extract.py /path/to/data_root`, where `data_root` contains the `Saves`, `Saves_EN`, `Saves_SC`, and `Saves_TC` folders.

This data is not particularly processed because it's getting merged with my existing data for barrelwisdom. But if you're looking for full Chinese text, you'll be disappointed.
